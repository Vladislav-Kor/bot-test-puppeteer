# bot-test Проверка ссылок и изображений

Этот проект использует Puppeteer для эмуляции пользователя, который просматривает сайт и проверяет:

- Наличие битых ссылок и страниц с ошибками 404  
- Пустые страницы и страницы с ошибкой  
- Не загружающиеся изображения на страницах  
- Сбор всех посещённых URL внутри сайта  
- Запись ошибок и проблемных ссылок в файл `error.php`  

---

## Установка

1. Установите Node.js и npm.  
2. Установите зависимости:  

npm install puppeteer

3. В скрипте замените переменную `glavUrl` на адрес вашего сайта.  

## Использование

Запустите скрипт командой:  

node <name file>


Сценарий запустит безголовый браузер, посетит страницы сайта рекурсивно, проверит ошибки и сохранит отчёт об ошибках в `error.php`.  

---

## Вывод ошибок

В файл `error.php` записываются:  

- Ссылки на страницы с ошибками  
- Ссылки на не загруженные изображения  
- Информация о типах ошибок и переходах между страницами  

## Примечания

- Скрипт ждёт до 30 секунд загрузки страницы и изображений.  
- Проверяются только внутренние ссылки, начинающиеся с основного URL.  
- В консоли цветом выделяются прогресс и ошибки для удобства отслеживания.
